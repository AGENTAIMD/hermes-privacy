Hermes Privacy Policy

Last updated: 25 September 2026

Who uses this app

Hermes is used only by its owner, on the owner's own computer. It is not distributed to anyone else.

Data accessed

With the owner's consent, Hermes requests read-only access to the owner's Gmail messages and settings and to the owner's Google Calendar events. It cannot send, delete or modify email, and it cannot change calendar events.

How the data is used

The data is used only to prepare the owner's personal daily briefing. To write the briefing text, relevant excerpts may be sent to the AI model provider that the owner has configured. The data is not sold, not used for advertising and not shared with anyone else.

Storage and retention

Google access tokens are stored only on the owner's computer and can be read only by the owner's user account. Briefings, and the logs Hermes keeps while preparing them, also stay on the owner's computer.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

Hermes's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
